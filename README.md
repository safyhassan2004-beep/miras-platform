# مِـرَاس (Miras) — المنظومة الوطنية الموثوقة للمهن والحرفيين
> المنظومة الرقمية المتكاملة لمنصة «مِـرَاس» مستخرجة ومنظمة بدقة متناهية من خدمتي **Stitch MCP** للمشروعين:
> - **مشروع البوابة الرئيسية وطالبي الخدمة:** `14671686482354917786`
> - **مشروع لوحتي تحكم الإدارة وأصحاب المهن:** `9491164590916363795`

---

## 🌟 نظرة عامة
تم تنظيم وتطوير المشروع في بيئة واحدة متناسقة دون دمج عشوائي للواجهات، وبفصل معماري كامل:
1. **البوابة العامة للعملاء وطالبي الخدمة (Public Portal & Client Flow):** تصفح المهن، البحث، تقديم الطلبات، والمصادقة.
2. **لوحة تحكم الإدارة (Admin Dashboard):** واجهة مستقلة وخاصة بإدارة المنظومة، الرقابة على سجل الكوادر الحرفية، والتحكم بالضمان المالي.
3. **لوحة تحكم أصحاب المهن (Professional Dashboard):** واجهة واحدة موحدة ومشتركة لجميع الحرفيين، مجهزة لعرض بيانات كل مهني حسب حسابه المسجل ديناميكياً.

## ⚡ جاهزية الربط مع Supabase ونظام الصلاحيات (RBAC)

تم تزويد كلا اللوحتين بملفات جافاسكريبت معيارية للربط المستقبلي بدون الحاجة لإعادة هيكلة الواجهات:

### 1. لوحة الإدارة (`admin/admin-auth.js`):
* يتحقق من وجود جلسة نشطة ومن وجود دور المشرف `role === 'admin'` أو `is_admin === true`.
* يحمي اللوحة ويعيد توجيه المستخدم غير المصرح له لصفحة تسجيل الدخول.
* جاهز للربط مع جداول Supabase: `profiles`, `craftsmen_verifications`, `escrow_contracts`.

### 2. لوحة الحرفي (`pro/pro-auth.js`):
* واجهة موحدة لجميع المهنيين؛ لا تعتمد على بيانات ثابتة.
* تستعلم تلقائياً من Supabase بناءً على معرف الحرفي المسجل:
  ```javascript
  supabase.from('craftsmen_profiles').select('*').eq('user_id', session.user.id).single()
  ```
* تدعم الحقول الديناميكية عبر وسوم `data-supabase-field` (مثل اسم الحرفي، رصيد المحفظة، التقييم، والطلبات النشطة).

## 🔗 خريطة التنقل المباشر
* **الدخول كعميل/فرد:** من [login.html](login.html) ➔ التحقق يوجهك إلى [الرئيسية](index.html).
* **الدخول كصاحب مهنة:** من [pro-login.html](pro-login.html) ➔ التحقق يوجهك مباشرة إلى [لوحة الحرفي](pro/index.html).
* **الدخول كمشرف/إدارة:** يوجد رابط مباشر أسفل [login.html](login.html) بعنوان «بوابة الإدارة والمشرفين» ➔ ينقلك إلى [لوحة تحكم الإدارة](admin/index.html).
* **العودة للبوابة الرئيسية:** يتوفر زر «بوابة مِـرَاس الرئيسية» في القائمة الجانبية لكلا اللوحتين.
* **التبديل بين الديسكتوب والجوال:** زر عائم أنيق أسفل كل صفحة يتيح المعاينة الفورية بين الشاشات.

## 🚀 كيفية المعاينة
افتح أي صفحة HTML بالنقر المزدوج في أي متصفح، أو شغل الخادم المحلي:
```bash
python -m http.server 8000
```
ثم توجه إلى:
* البوابة العامة: `http://localhost:8000/index.html`
* لوحة تحكم الإدارة: `http://localhost:8000/admin/index.html`
* لوحة تحكم المهنيين: `http://localhost:8000/pro/index.html`
