# دليل نظام التصميم والهوية البصرية — مِـرَاس (Miras Design System)
*الإصدار المعتمد لبناء واجهات المستخدم ولوحات التحكم (Dashboard & Admin Systems)*

---

## 1. فلسفة الهوية والاتجاه البصري (Design Philosophy)
منصة **«مِـرَاس»** هي منصة وطنية جامعة لأصحاب المهن والكوادر الحرفية وطالبي الخدمات. تعتمد لغتها البصرية على:
- **الموثوقية والوقار المؤسسي:** درجات الأزرق الكحلي الداكن المعتمد لإشعار الأمان، والتوثيق، وضمان الحقوق.
- **الهدوء والوضوح:** خلفيات دافئة ونظيفة مائلة للعاجي/الأبيض الطبيعي المريح للعين أثناء جلسات العمل الطويلة.
- **الحداثة والرشاقة:** زوايا منحنية متناسقة (Rounded borders)، وبطاقات ذات تباين ناعم وظلال خفيفة متدرجة تمنع الإجهاد البصري.
- **التوافق العربي الكامل (RTL First):** محاذاة مقروءة، تدرج هرمي منطقي للعين العربية.

## 2. باليتة الألوان الكاملة (Color Palette & Hex Codes)

| :--- | :--- | :--- |
| **Primary (الأساسي الداكن)** | `#00344d` / `#002b40` | أزرار الإجراءات الرئيسية (Primary Buttons)، الهيدر الداكن، العناوين الكبرى، الشارات المعتمدة |

| **Primary Container** | `#d2e8f8` | خلفيات الأزرار الثانوية الهادئة، إبراز العناصر النشطة المختارة |
| **On-Primary Container** | `#001e2e` | النصوص والأيقونات داخل الحاويات الزرقاء الفاتحة |
| **Accent / Cyan (التفاعلي الساطع)** | `#62b6cb` / `#5fa8d3` | الشارات، نقاط التحديد، أيقونات المؤشرات الحيوية، حدود التركيز (Focus state) |

- **Border Default (الافتراضي):** `#e0ded9` (حدود البطاقات والحقول العادية).
- **Border Subtle (الناعم جداً):** `#eae8e3` (خطوط الجداول والفواصل الأفقية).
- **Border Focus / Active:** `#00344d` أو `#62b6cb` بسماكة `2px`.

## 3. التايبوغرافي ونظام الخطوط (Typography System)

- **عائلة الخط المعتمدة:** `IBM Plex Sans Arabic` (مع بديل نظامي `Cairo` أو `system-ui, -apple-system, sans-serif`).
- **اتجاه النص الأساسي:** من اليمين إلى اليسار (`direction: rtl`).

### مقاسات الخطوط وأوزانها:
| التسمية (Token) | الحجم (px) | الارتفاع السطري (Line Height) | الوزن (Font Weight) | الاستخدام |
| :--- | :--- | :--- | :--- | :--- |
| **Display / H1** | `28px - 32px` | `1.3 - 1.4` | Bold (700) | عنوان الصفحة الترحيبي، أرقام الإحصائيات الضخمة |
| **Headline / H2** | `22px - 24px` | `1.4` | Bold (700) / SemiBold (600) | عناوين الأقسام الرئيسية، رؤوس بطاقات الإحصاء |
| **Title / H3** | `18px - 20px` | `1.4` | SemiBold (600) | عناوين البطاقات، عناوين النوافذ المنبثقة |
| **Subtitle / H4** | `15px - 16px` | `1.5` | Medium (500) | أسماء الأعمدة، عناوين القوائم المنسدلة |
| **Body Large** | `15px` | `1.6` | Regular (400) / Medium (500) | محتوى الجداول، التنبيهات المهمة |
| **Body Small** | `13px - 14px` | `1.5` | Regular (400) | الشروحات الفرعية، التلميحات المساعدة (Tooltips) |
| **Caption / Badge**| `11px - 12px` | `1.4` | Medium (500) / SemiBold (600) | الشارات، وسوم الحالة، أوقات المعاملات |

## 4. مكونات واجهة المستخدم وأنماطها (Component Patterns)

### أ. الأزرار (Buttons)
1. **Primary Button (الزر الأساسي):**
   - **الخلفية:** `#00344d` (Hover: `#002538`).
   - **لون النص والأيقونة:** `#ffffff`.
   - **الحواف:** انحناء خفيف ومتزن `rounded-xl` (`10px - 12px`).
   - **البطانة (Padding):** عمودي `12px` وأفقي `24px` (أو `h-11` إلى `h-12`).
   - **الخط:** وزن `SemiBold 600` بحجم `14px - 15px`.
   - **الأيقونات:** سهم توجيهي يسار الزر (`←`) أو أيقونة إجراء يمين النص.

2. **Secondary Button (الزر الثانوي / المحايد):**
   - **الخلفية:** `#ffffff` مع حد إطار `#e0ded9` (Hover: خلفية `#f4f3f1`).
   - **لون النص:** `#00344d` أو `#1b1c1d`.

3. **Subtle / Ghost Button (الزر الشفاف):**
   - **الخلفية:** شفافة `transparent` (Hover: `#eeebe6` أو `#d2e8f8` مع شفافية 40%).
   - **لون النص:** `#00344d`.

4. **Destructive Button (أزرار الحذف والإلغاء):**
   - **الخلفية:** `#ffdad6` مع نص `#ba1a1a`، أو زر أحمر صريح للعمليات الحرجة.

### ب. بطاقات المحتوى والإحصائيات (Cards & KPI Blocks)
- **الخلفية:** `#ffffff` الصافية مع تباين ناعم جداً على خلفية الصفحة `#faf9f6`.
- **الحدود (Border):** حد خارجي رفيع `1px solid #e0ded9`.
- **الاستدارة (Border Radius):**
  - بطاقات الإحصاء والبيانات: `16px` (`rounded-2xl`).
  - الحاويات الكبيرة ولوحات الجداول: `20px` إلى `24px` (`rounded-3xl`).
- **الظلال (Box Shadows):**
  - **الافتراضي (Elevation 1):** `0 1px 3px rgba(0, 0, 0, 0.04), 0 1px 2px rgba(0, 0, 0, 0.02)`.
  - **عند التحويم (Hover / Elevation 2):** `0 4px 14px rgba(0, 52, 77, 0.07)`.
  - **البطاقة البارزة (Accent Card):** بطاقة بخلفية زرقاء داكنة `#00344d` مع نصوص بيضاء وعناصر شفافة `#ffffff15`.

### ج. حقول الإدخال والبحث (Inputs & Form Controls)
- **الارتفاع (Height):** `46px - 48px` لتسهيل النقر والاستخدام المكتبي.
- **الخلفية:** `#ffffff` أو `#fbfbfa`.
- **الإطار:** `1.5px solid #e0ded9` يتحول عند التركيز (Focus) إلى `#00344d` أو حلقة ظل تركيز ناعمة `#d2e8f8`.
- **أيقونة الإدخال:** أيقونة رمادية خافتة `#73777f` على أطراف الحقل لمساعدة الإدراك البصري.
- **الاستدارة:** `12px` (`rounded-xl`).

### د. وسوم وشارات الحالة (Status Badges)
- شارات مدمجة صغيرة بارتفاع `24px - 28px` وبطانة أفقية `10px - 12px` بزوايا دائرية `rounded-full` أو `rounded-lg`:
  - **نشط / مكتمل / موثق:** خلفية `#e8f5ed` مع نص وأيقونة خضراء `#1b7a4d`.
  - **جديد / قيد التنفيذ:** خلفية `#e0f2fe` مع نص أزرق `#026aa7`.
  - **معلق / يحتاج مراجعة:** خلفية `#fef6e9` مع نص كهرماني `#b25e02`.
  - **ملغي / مرفوض:** خلفية `#ffdad6` مع نص قرمزي `#ba1a1a`.

## 5. شبكة المسافات والتخطيط (Layout & Spacing Grid)
يعتمد النظام على وحدة أساسية **8-point Grid System**:
- `4px` (`0.25rem`): المسافات الدقيقة بين الأيقونة والنص داخل الشارات.
- `8px` (`0.5rem`): المسافة بين عناصر القوائم الداخلية.
- `12px` (`0.75rem`): البطانة الداخلية للعناصر الصغيرة والحقول.
- `16px` (`1rem`): المسافة القياسية بين الحقول وبطاقات القوائم (Standard Spacing).
- `24px` (`1.5rem`): البطانة الداخلية للبطاقات (Card Padding)، والمسافة بين أعمدة لوحة التحكم.
- `32px` (`2rem`): التباعد بين الأقسام الكبرى في لوحة التحكم.

## 6. العناصر البصرية المشتركة للوحة التحكم (Dashboard Architecture)
عند بناء لوحة تحكم مِراس، يجب الالتزام بالتالي:
1. **الشعار المعتمد (Brand Mark):**
   - استخدام الرمز الأيقوني المعتمد الخالي من الحروف مع الاسم النصي «مِـرَاس» باللون الكحلي الداكن أو الأبيض على الخلفيات المظلمة.
2. **الشريط الجانبي (Sidebar):**
   - خلفية عاجية فاتحة `#f4f3f1` مع حد فاصل `#e0ded9`، أو خلفية كحلية `#002538` للنسخة الرسمية الفاخرة.
   - عنصر القائمة النشط (Active Item) يتميز بخلفية `#d2e8f8` ونص `#00344d` وشريط مؤشر جانبي.
3. **مؤشرات الثقة والأمان (Trust Indicators):**
   - دمج شارات التوثيق (أيقونة الدرع أو بصمة نفاذ الوطني) بلون كحلي وأخضر متزن.
4. **الجداول (Data Tables):**
   - ترويسة الجدول بخلفية `#f4f3f1` ونصوص شبه غامقة `13px`.
   - خطوط فواصل ناعمة `#eae8e3` بدون خطوط عمودية مزعجة، مع تأثير hover ناعم `#faf9f6` عند المرور على الصف.
